# יומן אימונים A/B — v2.0.1

Build: 2026-09-11

## מה חדש ב-v2.0.1
- לכל משבצת עם חלופות יש Drop-down לבחירת התרגיל שבוצע בפועל.
- לכל וריאציה נשמרת היסטוריה נפרדת. לדוגמה Machine Chest Press ו-Dumbbell Bench Press אינם מתערבבים.
- נוספו Prone Leg Curl, Converging Shoulder Press, Leg Extension ו-Captain's Chair Leg Raises.
- Triceps Pushdown נשאר תרגיל A כפי שהיה בתוכנית.
- לחיצה על שם תרגיל פותחת חלון עם איור אופליין, שלבי ביצוע, דגשים ואזהרות.
- שם קובץ הגיבוי וה-CSV כולל את גרסת האפליקציה.
- Wake Lock וטיימר המנוחה נשארו פעילים.

## שילוב התרגילים החדשים
- Prone Leg Curl: חלופה ל-Seated Leg Curl באימון A.
- Converging Shoulder Press: חלופה ל-Lateral Raise במשבצת הכתפיים של A. זו אינה החלפה זהה; היא נועדה לאפשר בחירה בלי להוסיף אוטומטית עוד נפח.
- Leg Extension: חלופה ל-Leg Press של אימון B (החשיפה השנייה לקוואד). ה-Leg Press המרכזי ב-A נשאר.
- Captain's Chair Leg Raises: חלופה נפרדת ל-Hanging Knee Raise באימון B.
- Triceps Pushdown: כבר קיים באימון A; לא הוכפל ב-B כדי לשמור שם את Overhead Cable Triceps Extension.

## התקנה
האפליקציה צריכה להיות מוגשת מ-HTTPS כדי לקבל התקנת PWA מלאה ו-Screen Wake Lock.

1. העלה את כל תוכן התיקייה לאחסון סטטי HTTPS.
2. פתח את הכתובת בטלפון.
3. בחר "התקנת אפליקציה" / "הוסף למסך הבית".
4. אחרי הטעינה הראשונה האפליקציה והאיורים עובדים גם אופליין.

## נתונים
הנתונים נשמרים ב-localStorage תחת אותו origin. אין שרת נתונים.
מומלץ לייצא JSON מדי פעם דרך הגדרות > ייצוא גיבוי.

## שדרוג מגרסה קודמת
היסטוריית אימונים ישנה נשמרת כי מפתח האחסון לא השתנה.
רשומות ישנות שבהן שם התרגיל היה משולב, למשל "Chest Press / Dumbbell Press", נשארות כפי שהן כדי לא לנחש איזו וריאציה ביצעת בעבר.
אימונים חדשים נשמרים לפי התרגיל הספציפי שבחרת.


## תיקון v2.0.1
